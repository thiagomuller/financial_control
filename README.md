# My Finances App

> **⚠️ AI-Generated Project Notice**
>
> This project was **almost entirely generated by AI** (Claude, by Anthropic), with minimal human intervention. It was built as a personal experiment and learning exercise. **Do not use this in production.** The code has not been audited for production readiness, and security trade-offs have been made that are only acceptable for a local, single-user, self-hosted environment (e.g., SHA-256 password hashing instead of bcrypt, no HTTPS, JWT secret in compose file defaults).

## What Is This?

A self-hosted personal finance manager. It tracks:
- **Bank accounts** — balances, icons, statements
- **Transactions** — categorised income/expense entries
- **Transfers** — balance moves between accounts
- **Tags** — user-defined labels for transactions and transfers
- **Goals** — savings targets distributed over a time interval
- **Recurring incomes/expenses** — automatically posted on a given day each month
- **Dashboard** — account summaries, tag statistics, upcoming items

## Tech Stack

| Runtime  | Rootless Podman + podman-compose |

## Prerequisites

- [Podman](https://podman.io/) with rootless support
- `podman-compose`
- (Optional) `distrobox` if running inside a distrobox container

> If you are running on a bare host (not inside distrobox) remove the `distrobox-host-exec` prefix from every command below.

## First-Time Setup

```bash
# 1. Clone the repository
git clone <repo-url>
cd financial_control

# 2. Create the DB data directory and fix permissions for rootless Podman + SELinux
mkdir -p db_data
distrobox-host-exec podman unshare chmod 777 ./db_data
```

## Running the App
```bash
podman-compose -f /home/$USER/financial_control/docker-compose.yml build && \
podman ps -a --filter "name=my-finances-ui" --format "{{.Names}}" | xargs -r podman stop && \
podman ps -a --filter "name=my-finances-api" --format "{{.Names}}" | xargs -r podman stop && \
podman ps -a --filter "name=my-finances-db" --format "{{.Names}}" | xargs -r podman stop && \
podman ps -a --filter "name=my-finances-ui" --format "{{.Names}}" | xargs -r podman rm && \

podman-compose -f /home/$USER/financial_control/docker-compose.yml up -d
```
